# RMO 1.0.0

RMO QuickLook helps users compare local ideal-MHD interpretations of plasma fronts under stated inputs and assumptions.

- **Solar events:** inspect published measurements, review an edited working copy, and save or restore a literature-input draft.
- **Model examples:** open saved Fast shock, Slow shock, Contact and Rotation examples, with results, plots and physical checks.
- **Synthetic inputs:** load a contact example or enter values, check the input, calculate a supported case, and save the input and computed result.
- **Online or local use:** use the hosted Python service at [rmo-solar.org](https://rmo-solar.org/) or follow the [local installation instructions](README.md#two-ways-to-use-rmo).

Saved examples, input checks and new calculations are labelled separately. Entered values remain available when the calculation service is busy. Available downloads include JSON and, where supported, PDF.

The scientific reference is R139. Local model consistency does not establish a unique global Riemann solution, full MHD coverage, stability or an observational identification. Verification scope and limits are described in [release acceptance](docs/RELEASE_ACCEPTANCE.md).
